# 📚 Papeer — Agentic Research Paper Assistant

> A LangGraph-based agentic RAG system for chatting with research papers, verifying claims, and searching the web for current findings.

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://papeer-rag-research-assistant.streamlit.app)

---

## ✨ Features

| Feature | Description |
|---|---|
| 📄 **Chat with Papers** | Upload PDFs, Markdown, or TXT files and ask questions about their content |
| 📡 **ArXiv Loader** | Load papers directly by ArXiv ID or paper title |
| 🔗 **URL Loader** | Scrape and load any public web page into the knowledge base |
| 🌐 **Web Search** | Queries the web via Tavily when current or supplementary information is needed |
| ✅ **Claim Verification** | Searches web and arXiv to check if a claim has been superseded by newer work |
| 💬 **Multi-Session Chat** | Separate conversation histories per session; session names generated by the LLM |
| ⚡ **`/btw` Side Channel** | Ask off-topic questions without touching the research session history |
| 📊 **Graph State Inspector** | Expandable panel showing the full LangGraph state for each turn |

## 🏗️ Architecture

```
User Query
    │
    ▼
┌──────────┐
│  Router  │  classifies query → retrieve / verify_claim / direct_answer
└──────────┘
     │
     ├─── retrieve ──────► ┌─────────────┐
     │                     │  Agent Node │ ◄────────────────────┐
     │                     │ (plans what │                      │
     │                     │  to search) │                 (max 3 retries)
     │                     └──────┬──────┘                      │
     │                            │ tool_calls                   │
     │                            ▼                             │
     │                     ┌──────────────────┐                  │
     │                     │    Tool Node     │──────────────────┘
     │                     │  - Vector Search │
     │                     │  - Web Search    │
     │                     └──────────────────┘
     │                            │
     │                     ┌──────▼───────────┐
     │                     │  Relevancy Check │
     │                     └──────────────────┘
     │                    relevant │ not relevant
     │                             │         │
     │                             │    ┌────▼──────────┐
     │                             │    │ Query Rewrite │──► Agent Node (once)
     │                             │    └───────────────┘
     │                             ▼
     ├─── verify_claim ──► ┌──────────────┐
     │                     │ Verify Claim │  (Tavily: general web + arXiv-targeted)
     │                     └──────┬───────┘
     │                            │
     └─── direct_answer ──────────┤
                                  ▼
                          ┌────────────────┐
                          │ Generate Answer│
                          └────────────────┘
```

### Graph Nodes

| Node | What it does |
|------|-------------|
| **Router** | LLM call → classifies query into `retrieve`, `verify_claim`, or `direct_answer` |
| **Agent Node** | LLM with bound tools decides what to search; catches LLM errors with a forced fallback retrieval |
| **Tool Node** | Runs `retrieve_from_vectorstore` or `web_search`; capped at 3 retrieval attempts |
| **Relevancy Check** | LLM judge — decides if retrieved chunks are relevant to the query |
| **Query Rewrite** | Rewrites the query with alternative keywords; runs at most once per turn |
| **Verify Claim** | Two Tavily searches (general web + `site:arxiv.org`) to find recent work on a claim |
| **Generate Answer** | Synthesises answer from retrieved context (hard-capped at 8,000 chars of context) |

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| **LLM** | `openai/gpt-oss-120b` via [Groq](https://groq.com) |
| **Orchestration** | [LangGraph](https://github.com/langchain-ai/langgraph) with `MemorySaver` checkpointing; fresh thread per turn |
| **Vector Store** | [Qdrant](https://qdrant.tech) in-memory (`:memory:`), one collection per session |
| **Embeddings** | `sentence-transformers/all-MiniLM-L6-v2` (384-dim, cosine) via `CacheBackedEmbeddings` + `LocalFileStore` |
| **Web Search** | [Tavily](https://tavily.com) |
| **Document Loaders** | PyMuPDF (PDF), TextLoader (TXT / MD), WebBaseLoader (URLs), ArXiv Atom API |
| **UI** | [Streamlit](https://streamlit.io) |
| **Evaluation** | [DeepEval](https://docs.confident-ai.com/) with a custom Groq judge |

## 🚀 Run Locally

### 1. Clone & install

```bash
git clone https://github.com/dummycodertech/research-assistant-agentic-rag.git
cd research-assistant-agentic-rag
pip install -r requirements.txt
```

### 2. Set environment variables

Create a `.env` file:

```env
GROQ_API_KEY=gsk_...
TAVILY_API_KEY=tvly-...
```

### 3. Run

```bash
streamlit run app.py
```

To deploy your own fork:

1. Fork this repo
2. Go to [share.streamlit.io](https://share.streamlit.io) → **New App**
3. Select your fork, branch `master`, entry point `app.py`
4. Add secrets under **Settings → Secrets**:

```toml
GROQ_API_KEY = "gsk_..."
TAVILY_API_KEY = "tvly-..."
```

> **Storage note:** Qdrant is in-memory. Documents uploaded in a session persist for the lifetime of the Streamlit worker process and are cleared on restart.

## 🧪 Evaluation

The pipeline was evaluated with [DeepEval](https://docs.confident-ai.com/) on **10 technical questions** generated from a long-form research report loaded into the system as a PDF. Scoring was done by a custom `GroqJudge` wrapper using `openai/gpt-oss-20b`.

```bash
python evaluate.py
```

### Results (pass threshold = 0.70, 10 test cases)

| Metric | Avg Score | Pass Rate |
|--------|-----------|-----------|
| Contextual Precision | 0.84 | 8 / 10 — 80% ✅ |
| Contextual Recall | 0.69 | 4 / 10 — 40% ⚠️ |
| Contextual Relevancy | 0.61 | 2 / 10 — 20% ❌ |
| Answer Relevancy | 0.75 | 6 / 10 — 60% ⚠️ |
| Faithfulness | 0.62 | 4 / 10 — 40% ⚠️ |

**Notes:**
- Contextual Precision was the strongest result — retrieved chunks are generally well-ranked relative to relevance.
- Contextual Relevancy was weakest — the retriever returns chunks that are topically adjacent but not always tightly scoped to the exact question, a known limitation of cosine-similarity retrieval without re-ranking.
- Recall and Faithfulness scores are partly affected by the density of the test questions, which covered multiple sub-topics per query.
- Full per-question scores and DeepEval reasoning strings are in [`eval_results.json`](./eval_results.json).

## ⚡ The `/btw` Command

Type `/btw <question>` to ask anything outside your research topic. The `/btw` handler does not touch the vector store or the main session checkpointer. It routes internally: Tavily web search for live questions; direct LLM response for stable general questions.

```
/btw What is the current price of gold?
/btw Explain the softmax function
```
